Tutoriales rapidos

LuckPerms: sistema de rangos completo

Paso 1: Instala LuckPerms y reinicia.
Paso 2: /lp creategroup helper
Paso 3: /lp group helper permission set essentials.kick true
Paso 4: /lp user nick parent set helper
Paso 5: /lp editor para gestion visual.
